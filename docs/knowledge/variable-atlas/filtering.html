处理发生在构建时

Maven 读取源文件并复制替换后的内容。产物里的值在本次构建时确定，源文件保持原样。

过滤格式与范围

当前项目的 Spring Boot 父 POM 使用 @...@ 分隔符。示例适用于已启用过滤的文本资源。

资源与传值示例

假设资源文件启用了过滤，可以通过 POM 属性或本次命令提供值。

# src/main/resources-filtered/application.properties
app.label=@app.label@

# pom.xml 中的 properties
<app.label>pom-value</app.label>
./mvnw package -Dapp.label=cli-value

过滤属性文件

在构建配置的 filters 中指定属性文件，再对专门存放文本资源的目录启用过滤，其他资源原样复制。

<build>
    <filters>
        <filter>filters/build.properties</filter>
    </filters>
    <resources>
        <resource>
            <directory>src/main/resources</directory>
            <filtering>false</filtering>
        </resource>
        <resource>
            <directory>src/main/resources-filtered</directory>
            <filtering>true</filtering>
        </resource>
    </resources>
</build>

图中的顺序限于 Maven 3.9.12、Resources Plugin 3.5.0 的同名普通属性示例。
