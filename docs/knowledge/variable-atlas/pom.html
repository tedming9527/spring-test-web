读图时留意

环境变量需要明确引用

APP_LABEL 不会自动变成 app.label。在 POM 中用 ${env.APP_LABEL} 读取它，或在属性值中显式建立映射。

示例的适用范围

顺序针对普通同名属性的演示。project.* 等模型表达式和具体插件配置应按各自规则判断。

使用与传值示例

POM 可以通过普通属性引用环境变量；命令行也可以为本次构建传入同名属性。

<properties>
    <app.label>${env.APP_LABEL}</app.label>
</properties>
<build>
    <finalName>${app.label}</finalName>
</build>
APP_LABEL=env-value ./mvnw package
./mvnw package -Dapp.label=cli-value

常见属性名称

${project.version} 来自 Maven 项目模型，${maven.version} 表示 Maven 版本，${java.home} 和 ${user.home} 是 JVM 系统属性，${env.PATH} 引用环境变量。
